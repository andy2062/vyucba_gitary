Prípravné prstové cvičenia

Zameranie: Osamostatnenie (nezávislosť) prstov ľavej ruky.

  • Komentár pre študenta: Položíme prsty ľavej ruky v VII. poli na tretiu (G) strunu do každého poľa jeden prst. Prsty dávame tesne pred pražec! Strunu jemne stláčame a uvoľňujeme.

  • Technický tip: Pri dvíhaní a ukladaní viacerých prstov sa snažíme, aby všetky zodvihnuté alebo ukladané prsty sa súčasne zdvihli alebo položili na strunu.

    • Dvíhanie jedného prsta:

  • 1., 2., a 3. prst necháme ležať, dvíhame 4. prst a kladieme ho späť.

  • 2., 3., a 4. prst ostanú ležať, dvíhame a ukladáme 1. prst

  • 1., 3., a 4. prst ostanú ležať, dvíhame a ukladáme 2. prst

  • 1., 2., a 4. prst ostanú ležať, dvíhame a ukladáme 3. prst

    • Dvíhanie dvoch prstov:

  • 3., a 4. prst ostane ležať, dvíhame 1. a 2. prst

  • 1., a 2. prst ostane ležať, dvíhame 3. a 4. prst

  • 1., a 4. prst ostane ležať, dvíhame 2. a 3. prst

  • 2., a 3. prst ostane ležať, dvíhame 1. a 4. prst

  • 1., a 3. prst ostane ležať, dvíhame 2. a 4. prst

  • 2., a 4. prst ostane ležať, dvíhame 1. a 3. prst

    • Dvíhanie troch prstov:

  • 1. prstostane ležať, dvíhame 2., 3., a 4. prst

  • 2. prst ostane ležať, dvíhame 1., 3., a 4. prst

  • 3. prst ostane ležať, dvíhame 1., 2., a 4. prst

  • 4. prst ostane ležať, dvíhame 1., 2., a 3. prst
